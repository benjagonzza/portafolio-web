# Portafolio Web Autoadministrable

## Descripción
Sistema web dinámico desarrollado con PHP, MySQL, HTML, CSS, Bootstrap y JavaScript.

Permite administrar un portafolio profesional con sistema de login, dashboard y CRUD de proyectos.

---

## Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript
- PHP
- MySQL
- AJAX (básico)
- GitHub

---

## Funcionalidades
- Sistema de login con sesiones
- Dashboard administrativo
- CRUD de proyectos (crear, leer, actualizar, eliminar)
- Portafolio dinámico conectado a base de datos
- Formulario de contacto
- Diseño responsive

---

## Instalación
1. Clonar repositorio
2. Importar base de datos `bd.sql` en phpMyAdmin
3. Configurar conexión en `/config/conexion.php`
4. Ejecutar en XAMPP o servidor local

---

## Enlace a producción
http://localhost/portafolio-web
(Después reemplazar por servidor TECLA)
